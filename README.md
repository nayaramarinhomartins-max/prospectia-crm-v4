# ProspectIA CRM v4

Sistema CRM completo de prospecção e vendas com backend Python — desenvolvido com HTML, CSS, JavaScript e Flask.

## Sobre o projeto

Plataforma de gestão comercial com foco em automação de prospecção B2B, captura de leads, SDR automatizado e pipeline de vendas.

## Módulos

- **Dashboard** — visão geral de métricas e performance
- **Leads** — gestão e qualificação de prospects
- **Pipeline** — funil de vendas visual
- **Captação** — captura automática de leads via Google Maps
- **SDR** — assistente de vendas automatizado
- **Conversas** — histórico de interações por lead
- **Campanhas** — gestão de campanhas de prospecção
- **Carteira** — gestão de clientes ativos
- **Ligações** — registro e acompanhamento de ligações
- **SMS** — envio de mensagens em massa
- **Gráficos** — análise de performance
- **Configurações e Planos**

## Stack

**Frontend:**
- HTML5, CSS3, JavaScript puro
- Arquitetura modular com componentes reutilizáveis

**Backend:**
- Python + Flask
- Scraper de leads via Google Maps (Playwright)
- Integração com Supabase

## Como rodar

**Backend:**
```bash
cd backend
pip install -r requirements.txt
python server.py
```

**Frontend:**
Abra o `index.html` no navegador ou sirva com servidor estático.
